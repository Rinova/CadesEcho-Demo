# Cade's Echo — Demo

A dark atmospheric clicker/idle game about reconstructing signals, opening increasingly rare chests and pushing deeper through six tiers.

## Current playtest

The current Windows build is **0.1.0-demo.3**. Download the installer from the [latest release](https://github.com/Rinova/CadesEcho-Demo/releases/latest).

- Windows 10/11, 64-bit
- German and English
- Local save games, no account required
- Early demo: content and balancing may change

## Integrity

A SHA-256 checksum is attached to every release. Windows may display a SmartScreen warning because this small playtest installer is not code-signed yet.

This public download repository does not contain the game's source code. GitHub's automatically generated “Source code” archives contain only this public README.

## Feedback

Please report crashes, unclear systems, balancing issues and anything that interrupts the game flow through this repository's Issues tab.
